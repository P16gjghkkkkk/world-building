Publish with GitHub Pages
1. Upload index.html, style.css and script.js to the root of your repository.
2. In GitHub, open Settings > Pages.
3. Select Deploy from a branch, choose main and / (root), then Save.
4. Your site will be published at the GitHub Pages address shown there.

Before publishing
- Confirm all project descriptions and education details.
- Add a professional photo if you want one; the current hero uses an abstract graphic.
- Add a LinkedIn URL only after confirming the exact profile address.
- The email and GitHub links are included from your previously supplied portfolio details.
